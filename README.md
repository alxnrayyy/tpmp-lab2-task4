## Overview
Программа для обработки данных школьников. Выводит список учеников 5-х 
классов.

## Author
Юрченко Александра, группа 10

## Usage
make
make run

##Modules

pupil.h/c — структура и функции для работы с данными школьника
file_io.h/c — работа с файлами
process.h/c — обработка данных (фильтрация по классу)
main.c — точка входа

## Additional Notes
Исходные данные читаются из файла pupils.txt
Результат сохраняется в result.txt
Тесты в папке docs/
