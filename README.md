## Usage
1. Клонировать репозиторий:
git clone git@github.com:alxnrayyy/tpmp-lab2-task4.git

2. Перейти в папку проекта:
cd tpmp-lab2-task4

3. Собрать программу:
make

4. Запустить:
make run


## Additional Notes
- Исходный код в папке `src/`
- Для сборки используется Makefile
